# Creating an App for Foundry VTT

If you have never used it, **Foundry Virtual Tabletop (FoundryVTT)** is a self-hosted platform for running tabletop RPGs online. It provides a shared game board with maps, tokens, dice rolling, chat, character sheets, combat tracking, and automation tools so groups can play remotely while keeping the feel of an in-person session.

One of the reasons I like it so much is that Foundry is highly extensible: you can build modules, customize systems, and integrate third-party tools through its API. This post will walk through creating an app that plugs into that ecosystem and extends what Foundry can do.
